# 김사부의 등기부 판독기 — 배포 저장소

등기사항전부증명서(전자 PDF · 스캔 PDF)를 읽어 갑구·을구 등기와 말소 여부를 정리하고, 원본과 대조해야 할 칸을 표시하는 Windows 프로그램입니다.
만든 사람: 김종엽 변호사 (김사부) · 소개 사이트: https://deunggibu-reader.vercel.app

> 이 저장소에는 **설치 파일과 안내 문서만** 있습니다. 프로그램 소스는 공개하지 않습니다.

## 사용 승인제
- 설치한 뒤 처음 켜면 **설치판 사용 신청** 화면이 나옵니다. 이름·소속·이메일·연락처를 넣고 신청하세요.
- 만든 사람이 **승인해야** 판독 화면이 열립니다. 승인 전에는 판독 기능이 켜지지 않습니다.
- 승인 확인은 켤 때와 쓰는 동안 3시간마다 합니다. 인터넷이 잠시 끊겨도 마지막 확인부터 3일까지는 그대로 쓸 수 있습니다.
- 승인이 해제되면 프로그램이 잠깁니다. 이 PC에 저장한 파일은 지워지지 않습니다.
- 승인 확인 때 보내는 것: 신청할 때 넣은 이름·소속·이메일·연락처, 이 PC의 기기 번호, 프로그램 버전. **등기부 PDF·OCR 결과·분석 결과는 보내지 않습니다.**

## 내려받기
**[최신 버전 내려받기 → Releases](https://github.com/kjy71111/deunggibu-reader-releases/releases/latest)**

| 파일 | 설명 |
|---|---|
| `RegistryReader-<버전>-Setup.exe` | Windows 설치 파일 |
| `SHA256SUMS.txt` | 파일 위변조 확인용 SHA-256 값 |

다른 분께 알려 줄 때는 설치 파일을 직접 보내지 말고 소개 사이트나 이 저장소 주소를 알려 주세요.

## 지원 환경
| 운영체제 | 상태 |
|---|---|
| Windows 10 / 11 (64비트) | 지원 |
| macOS | 지원 안 함 |

스캔 PDF를 읽으려면 Windows의 한국어 문자 인식(OCR)이 설치돼 있어야 합니다(Windows 설정 > 시간 및 언어 > 언어 및 지역 > 한국어 언어 옵션).

## 설치할 때
1. `RegistryReader-<버전>-Setup.exe`를 실행합니다.
2. "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]** 을 누르세요. (코드 서명을 하지 않은 프로그램이라 처음에 뜨는 경고입니다)
3. 사용권 계약에 동의하고 설치를 마칩니다. 설치 비밀번호는 없고, 관리자 권한 없이 사용자 폴더에 설치됩니다.

## 파일 위변조 확인 (SHA-256)
내려받은 파일의 값이 Releases에 있는 `SHA256SUMS.txt`의 값과 같은지 확인하세요.

PowerShell:
```powershell
Get-FileHash .\RegistryReader-1.0.0-Setup.exe -Algorithm SHA256
```
명령 프롬프트:
```bat
certutil -hashfile RegistryReader-1.0.0-Setup.exe SHA256
```
값이 다르면 실행하지 말고 다시 내려받으세요.

## 알려진 제한
- **판독 결과는 업무 보조 수단입니다.** 표시된 '확인 필요' 칸은 반드시 등기부 원본과 대조하세요. 확인 필요가 0건이어도 중요한 판단 전에는 원본을 확인하세요.
- **스캔 PDF는 문자 인식(OCR)을 거칩니다.** 글자를 잘못 읽을 수 있어 전자 PDF보다 확인할 칸이 훨씬 많고(실측 약 절반), 처리에 쪽당 6~8초쯤 걸립니다. 스캔 문서는 외부 AI 추론으로 보내지 않고 이 PC의 규칙 판독만 씁니다.
- 외부 AI(Anthropic API) 추론은 기본으로 쓰지 않습니다. 사용자가 직접 API 키를 넣고 실행할 때만 전자 PDF의 추론 자료가 Anthropic으로 전송되며, 스캔 문서가 하나라도 있으면 이 기능은 막힙니다.
